# 3-1 Intermediate Practice (electronic worksheet)

`index.html` is the 3-1 worksheet (solving systems of equations, problems 1–13) as an interactive page. Open it in a browser.

- **Help** gives a hint, then more help, then the full solution.
- Using **More help** or the full solution means the student does a similar problem (up to 3) before moving on.
- When finished, students get a **teacher code** tied to their name. Open the page with `#teacher` at the end of the address (or click "Teacher: read student codes") to read one code or paste a whole class.
- **Restart worksheet** at the end erases the work on that device and starts a new attempt.

Published artifact: https://claude.ai/artifact/Y1ZwVvFwsjdzh6LvRizhbU

# Intermediate 3-1 Haunted House (escape room)

`Intermediate-3-1-Haunted-House.html` turns the same 13 problems into a Halloween escape room. It is one self-contained file. Open it in a browser or serve it with GitHub Pages.

- Students pick a character and walk around the haunted house with the arrow keys or WASD, by tapping the map, or with the on-screen arrow buttons.
- Each of the 13 doors holds one worksheet problem. A correct answer earns a letter of the magic phrase. At the front door, students put the 13 letters in order to escape.
- **Help** works like the worksheet: a hint, then more help, then the full solution. Using More help or the full solution means solving a similar problem before the door gives up its letter.
- The music and sound effects are made in the browser, so there are no audio files. Students can turn either one off.
- After escaping, students get a **teacher code** tied to their name. They can also print the review or save it as a PDF, download it, or press **Play again**.
- To read codes, open the page with `#teacher` at the end of the address, or click "Teacher: read escape codes". These codes are separate from the plain worksheet's codes.
